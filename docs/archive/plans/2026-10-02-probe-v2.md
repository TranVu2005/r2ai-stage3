# Probe v2 Implementation Plan

> Execute inline with systematic debugging, regression tests and verification.

**Goal:** Implement and run the user's supplied steps 2–4 without modifying source data.
**Spec:** User attachment `Văn bản đã dán.txt` (2026-10-02).
**Architecture:** Shared fetcher owns classification, per-host pacing, robots, cookies and metadata. Separate CLI stages own deterministic sampling and append-only checkpoints; a shared report combines measured observations with explicit unknowns.
**Tech stack:** Python, requests, polars, trafilatura, transformers BGE-M3, warcio, unittest.

## Global constraints
- Seed 42; preserve query strings; deduplicate HTTP/HTTPS before sampling.
- 15s timeout; at most 2 retries for 429/5xx; one cookie retry.
- At most one request/second/host, including redirects, robots and retries.
- Robots denial/unavailable is recorded; never bypass captcha or use proxies.
- Ten exclusive states; unknown measurements stay unknown, never become zero.
- CLI `--domains`, `--n`; durable resume with deterministic sample manifests.

## Review focus
- HTTP 502/521 without extraction must become dead_origin.
- Literal cookie challenges precede empty SPA detection; captcha in an article must not classify it as blocked.
- Cross-host redirects must check robots and pacing on the destination.
- Partial archive query failures cannot prove absence; partial samples cannot represent unmeasured domains.
- Resume cannot duplicate rows or mix experiments with incompatible configurations.
